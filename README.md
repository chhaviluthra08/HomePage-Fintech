# SecurePay Landing Page

A modern, responsive, dark-themed landing page designed for a fictional fintech payment gateway. This project is built entirely with semantic HTML, advanced CSS, and Vanilla JavaScript, showcasing high-performance UI components and animations without the overhead of external frontend frameworks.

## Features

* **Responsive Design:** Fully fluid layout utilizing CSS Grid and Flexbox, optimized for desktop and mobile viewing.
* **3D Interactive Hero:** A floating credit card mockup that tilts dynamically based on mouse movement.
* **Scroll Reveal Animations:** Content gracefully fades and slides into view as the user scrolls, powered by the Intersection Observer API.
* **Infinite Ticker:** A continuous, seamless CSS marquee displaying platform statistics.
* **Interactive UI Elements:** * Dynamic tabbed navigation to switch between product categories.
    * Expandable FAQ accordion.
    * Hover-triggered styling and transitions on cards and buttons.
* **Advanced CSS Visuals:** Features glassmorphism (backdrop filters), custom mesh gradients, orbiting elements, and continuous floating animations.
* **Zero Dependencies:** Completely framework-agnostic. No React, Vue, Tailwind, or jQuery required.

## Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Custom properties (variables), Grid, Flexbox, keyframe animations, and transitions. 
* **JavaScript (ES6+):** DOM manipulation, event handling, and Intersection Observer logic.
* **Typography:** Google Fonts (Bricolage Grotesque for headings, Inter for body copy).

## Getting Started

Since this is a static frontend project, there is no build process or server setup required.

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/securepay-landing.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd securepay-landing
    ```
3.  Open the `index.html` file in your preferred web browser.

## Project Structure

The entire application is self-contained within a single file for easy portability and rapid deployment:

* `index.html`: Contains all markup, inline CSS (`<style>`), and inline JavaScript (`<script>`).

## Disclaimer

This is a static frontend mockup created for portfolio and educational purposes. The contact forms, login buttons, and code snippets are strictly visual and do not connect to a real backend, database, or live payment processing API.
